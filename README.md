# dave.portfolio

Source of the portfolio site "portfolio web dave". Work in progress.

- `mockup/index.html`: mockup v0.1, a demo, not the site. Every MISSING label is material still to come.
- `.pages.yml`: the console (Pages CMS). One collection per type of work; each work picks its props.
- `content/`: what the console writes (works, disciplines, board anchors).
- `public/media/`: files uploaded through the console.

This repository is public: upload a work only once it is ready to go public.
Files larger than 100 MB are refused by GitHub.
